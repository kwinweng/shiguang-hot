# 拾光热榜 PLAN

## 需求（2026-10-24 阿欢定稿）
### 页面
- 底栏 3 格：资讯 / 探索 / 我的；删除今日页，默认进资讯。收藏、设置、关于在「我的」。
- 资讯：实时（默认）/ 热点 / 回顾。热点每天 22:00 日报后显示当天全部热点，之前显示前一天并标日期；回顾沿用日期切换，不做日历。
- 资讯 3 标签和探索 3 标签都能下拉刷新：绕过缓存读最新已发布数据（每半小时抓一次），提示「新增 N 条」或「已是最新」，不现场抓取。
- 探索：好玩（吃喝、出行、温泉、游戏）/ 好看（剧、电影、小说、展览）/ 好买。
- 列表统一行布局 C；含无图详情页；红色只用于可点击；Logo D（关于页、favicon、App 图标）。
- 状态：加载中、空态、出错、离线、404（「回到资讯」）。
- 不做：登录、评论、分享卡、推送、下单支付、个性化推荐。
- 来源：`plan/FULL-SITE-PAGES-20261024.md`；实现 Spec：`docs/spec/SPEC-two-modules-20261024.md`。

### 成功标准（2026-10-24 11:32 定稿，上线两周后产品复盘）
1. 上线后两周里，阿欢一周至少有 5 天打开热榜看。
2. 热点每天 22:30 前更新好，两周里断更不超过 1 次。
3. 实时下拉刷新后，看到的内容最多晚半小时左右。
4. 探索每天都有新条目，阿欢两周里至少点开或收藏过 3 条好玩、好看或好买。
