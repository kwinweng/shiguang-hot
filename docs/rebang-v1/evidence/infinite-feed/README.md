# 一直往下刷 + 卡片只留长按菜单（2026-11-16）

频道区和博主区各变成一条连续的长流：一段刷完自动接下一段（中间一条「下一个：…」），最后写「内容已结束」。收藏和热搜只在本页里一直往下刷，不串到别的页。左右滑（仅「左右」模式）和点顶部图标都跳到那一段的开头。卡片去掉左滑收藏 / 右滑分享，一律长按弹菜单。旧的 `#/more/…` 链接跳进长流里对应的那段。

## 滚动性能（390×844，CPU 4 倍降速，中位数 3 次）

场景：左右滑到财经后再上划 40 次（deep）；博主页 X 上划 25 次（blogger）。掉帧 = rAF 间隔 >34ms；长任务 >50ms。两次都没有往回跳（`back_jumps = 0`）。

| 场景 | 指标 | 改前 | 改后 |
| --- | --- | --- | --- |
| 频道深刷 | 掉帧 | 15 | 17 |
|  | 最长帧 | 116.6 ms | 133.3 ms |
|  | 长任务 / 总时长 | 15 / 1195 ms | 10 / 723 ms |
|  | CLS | 0 | 0.0522（复测 0） |
| 博主深刷 | 掉帧 | 2 | 7 |
|  | 最长帧 | 116.7 ms | 116.7 ms |
|  | 长任务 / 总时长 | 0 / 0 | 2 / 136 ms |

改后刷得更远（财经频道会自动加载下一批，博主会串到后面的平台），所以掉帧略多、长任务总时长反而更短。复测见 `perf-after-probe.json`（频道 CLS 为 0）。
