## B：「今日重点」只认独立双源（与 A 并行，单独发布）

- 对已有**频道新闻**判断，不针对博主或热搜。以本轮固定构建时刻为准，最近 24 小时内（含两端、未来不计），至少两家可区分的独立来源报道**同一具体事件**才标；可跨频道取证但不搬条目，不改 ID、排序、折叠规则和正文链接。0 个符合也可以；不加权、凑数、排名、推送，不引入付费模型或外网识别。
- **同稿不是双源。** 同来源连发、来源别名/镜像、指向同一篇原稿的转载、明确转引同一出处的副本只算一份；`source_id` 不同本身不是证据。使用现有配置可证实的来源身份及原始报道字段，不拿大平台的共同托管域名当全体来源的身份。来源或事件有疑义时不标，不编造出处。
- **同题材不是同事件。** 允许不同媒体用不同标题/链接报道同一事实；第一版仅接受离线可解释的强证据（明确事件标识，或可复核的主体、动作及版本/地点/对象等区分信息相符）。仅关键词重合、译文相同、每天重复的栏目名不够；否定/传闻与正式发布、不同版本或数字不能合。不能靠 #88 的折叠组大小，也不能以 A≈B、B≈C 的传递关系推出 A≈C。
- 只复用现有重点标。既有 `hot-daily` 可以是线索，但不是独立第二来源；兼容旧输入不能让单源标、过期标或孤立整理稿绕过新规则。历史归档不回写。确定的双源不另设未确认的榜单配额。频道/正文的标记须一致；同频道折叠、主/副条深链不退化。
- **覆盖验收不是单品牌演示。** 在固定时钟与可确认的独立采编来源下，财经利率动作、公共设施开通、法院对有编号案件的裁决、技术发行均须有可复跑的异稿正例，至少一类有中文原题；替换未在代码中列举的主体、对象、编号、数值或版本，结果仍随事实成立。每类都配一个邻近却不同的事件（方向翻转、对象/案件/城市不同、数值或单位不同、拟议而非已发生）。不要求穷尽自然语言，也不接受靠添加品牌、地点或验收标题白名单达标；不确定可不标。报告每类命中与未命中，不把合成集换算成线上准确率。
- 先写固定时钟的正反例：不同来源/不同原始链接、不同措辞报道同一具体事件应标；跨频道互证但分组不动；单源重复/同稿两入口/旧整理标独自存在/模糊相似/同主体不同事件/反向事实不标；24 小时边界、未来、缺字段、乱序、重复构建不积累旧标。用合成数据验一次从构建到频道 JSON 与正文索引的输出，区分假阳性与已知漏标；不动前端样式、不改旧站或私聊推送。
