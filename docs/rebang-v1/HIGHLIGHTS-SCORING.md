# 今日重点判定

建站时用同一个时钟，在含两端的 `[now − 24h, now]` 内找至少两家独立采编来源对同一具体事件的报道。可以跨频道取证。符合条件的新闻使用现有「今日重点」角标，`highlight_date` 取构建时的北京时间日期。证据不足时可以是零条。

使用原文标题里的显式信息。当前有四类中文和英文句式，每篇报道必须独立给出全部字段，同一个键里的报道才能互证。

- 利率决议保留具名央行、升降方向、利率种类、调整后的明确百分比。调整幅度不是最终利率：标题必须写明结果；正文明确说方向相反，或本次决定维持利率不变，都不能给升降息标题作证。仅陈述调整后的现行利率不等于维持不变。同一句同时谈到相反走势时可能漏标。
- 设施启用保留具名地点和具名桥、线或隧道，接受正式开通、通车等同义动作。
- 法院裁决保留具名法院和明确案号，接受发布裁决等表达。有不同裁决阶段、结果或其他修饰信息的复杂标题不进入这条规则。
- 技术发行保留标题提供的发布者、产品或项目和完整的数字版本，接受正式发行的常见动词。

整句须符合支持的句式。机构、地点与产品名按原文保留。日期、地区限定、金额、测试版、传闻、否定、问句及预告等都可能改变含义，证据有歧义时不标记。暂时没有中英互译、名称别名关联或自由改写匹配，也没有用正文补齐缺失的事件字段。案号或其他字段完全相同的重复事件如果没有在标题体现出区别，仍可能无法区分。

采编身份用已配置的编辑部订阅 ID 和其自有文章域名共同确认。BBC 两个域名属于同一家；官方厂商博客、Telegram 聚合账号和共享托管链接缺少这里需要的独立采编证据。两篇报道需要各自的文章链接、不同的原标题和足够的原文内容。同一规范化链接、可见的转载或通讯社署名、明确引用/转发字段、连续八词或十六个汉字的相同片段都不足以证明独立性。订阅项或继承的结构化来源/署名不能证明是本站采编时不计票：只保存「有无声明」标志，不记录姓名、邮箱或来源地址；未知的旧缓存也不当成无署名。此规则可能漏掉有正常记者署名的独立稿。正文只能否决，不能补票。标题写成已发生，正文却明确说该动作仍在计划中（如「大桥将于下周通车」或「新版计划下月发布」），这篇不计票也不打标；其他两篇独立实报仍可互证。不会仅凭 `will` 或「将」就否决无关的后续安排。这些规则只覆盖明确句式，不保证识别所有改写。现有字段无法可靠识别无署名转载或改写稿。验证使用合成数据。

满足互证条件后，同一时间窗内指向已获互证的报道且原标题相同的直接副本也可显示角标。旧 `hot-daily` 新闻和旧标记不能提供票。频道折叠保持原主条和深链选择，选完后才给公开分页、banner 和折叠详情替换标记。搜索快照不带角标。重采同一条带旧标的新闻，如果只变了抓取时间、输入不再带旧标，归档中的 `first` 和 `latest` 都保持原样；真正改稿仍按原增量流程更新 `latest`。
