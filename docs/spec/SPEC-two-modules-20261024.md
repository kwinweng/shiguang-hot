## 1. 要做什么
1. **底栏 3 格**：资讯 / 探索 / 我的。删除「今日」页；打开站点默认进资讯。收藏、设置、关于收进「我的」。
2. **资讯 3 个标签**：实时（默认）/ 热点 / 回顾。
   - 热点：每天 22:00 日报出来后显示当天全部热点；之前显示前一天的，并标「M月D日的热点 · 今晚 22:00 更新」。点开原地展开摘要和来源。没内容「这一天没有热点」。
   - 回顾：沿用现有日期切换（‹日期›、昨天/今天、横滑日期条），不做日历。「今天」未生成显示「00:30 后生成」。
3. **下拉刷新**：资讯 3 标签 + 探索 3 标签。状态：下拉刷新 → 松手刷新 → 正在刷新 → 提示「新增 N 条」或「已是最新」。实现：绕过缓存重新读已发布数据（如 `fetch(url, {cache:'no-store'})` 或加时间戳参数），N 为新数据中旧列表没有的条目数。不做现场抓取，不加服务器。
4. **探索**（原好玩好买）：标签 好玩 / 好看 / 好买。好看＝剧、电影、小说、展览；好玩＝吃喝、出行、温泉、游戏。某分类无数据时不显示该分类，不编造条目。
5. **统一行布局 C**（所有列表）：左侧 64px 分类列；标题最多 2 行；摘要 2 行；灰色时间·地点一行；有图时右侧 76×76 缩略图，无图占满整行，图加载失败降级为纯文字。
6. **详情页**：含无图条目的详情页。
7. **颜色**：红色只用于可点击的东西。
8. **Logo D**：用于关于页、favicon、App 图标（`web/assets/*` 全套重生成，含 manifest）。
9. **状态**：加载中（骨架屏）、空态、出错（带「重试」）、离线（显示缓存 + 顶部提示）、404（按钮「回到资讯」）。亮/暗两套。
10. **修 DESIGN.md**：main 上没有 DESIGN.md；以 `/workspace/codex-runs/rebang-14/DESIGN.md` 为底稿放到仓库根目录，删掉过时的加粗规则（「标题600」「底栏选中加粗」「轻列表标题600」等），改为：**全站只有详情页 24px 标题加粗，其余一律不加粗**；并把列表、底栏、资讯标签等描述更新为本 Spec。
