把 `trial-sources.json` 里试跑的 13 个源变成站上「好玩」「好买」两个栏目，与新视觉一起上线。用户在手机上（iPhone 17 Pro 尺寸）能按时间新→旧看到北京周末玩什么、数码/3D 打印买什么；缺图、缺日期的条目也要好看、不误导。

## 3. 每日量假设（**暂定**，第 2–3 天数据出来后修订）
- 285/298 是 21:22 第一轮的存量；之后每小时一轮只新增 6–7 条（每源 0–2 条）。
- 暂按 **每天约 50–150 条新增**（全部 13 源合计）设计；单个分类每天可能只有 0–5 条。
- 设计含义：首页每块 5 条（MRD 第 4 条）时，必须允许回看最近 N 天（默认 7 天，与图片缓存 14 天内一致），不能只显示「今天」，否则很多块会空。
- 工头在 10/24 晚用运维统计修订本节，一周后定稿。

## 4. 抓取、去重与日期
- 继续沿用现有 `shiguang/ingest/web.py` / `shiguang/ingest/trial.py` 和 `tg.db`，**不改 schema**；如 Codex 发现必须加列，先停下来报给工头，由阿欢单独批。
- 去重（MRD 第 5 条「同一件事只留一条」）：
  1. 规范化 URL（去 utm_*、尾斜杠、fragment）相同 → 同一条；
  2. 同分类内，规范化标题（去空白、标点、全半角统一、小写）相同或相似度 ≥ 0.9 且 48 小时内 → 同一条，保留有图/字段更全/更早的一条；
  3. 不跨栏目去重（好看资讯与好玩好买互不影响）。
- 无日期条目（douban-events、ucca）：
  - 先尝试从标题/摘要解析活动日期，如 ucca「2026.7.14 - 2027.1.31」→ 展期；解析成功则显示「展期 7/14–1/31」，并用于判断是否已结束（已结束不展示）。
  - 解析失败：排序用**首次抓到时间**（first_seen），卡片显示「最近收录」而不是假日期；不得把抓取时间显示成发布/活动时间。

## 5. Apps_Share 标题清洗
- 现状：标题形如「标签： 内购限免、工具、生活」，没有 App 名。
- 规则：若标题以「标签：」开头，则从正文/摘要第一行或链接里取 App 名做标题；标签串转为卡片上的标签（如「内购限免」「工具」），最多 3 个。
- 取不到 App 名：该条不展示（计入日志 `apps_share_untitled`），不显示一串标签当标题。
- 加单测覆盖：正常标题不变；标签标题被替换；取不到时被过滤。

## 6. 无图 / 无日期兜底样式
- 无图（douban-events、apple-newsroom、appinn、earthsky、ucca 全部无图；steam 95% 无图）：瀑布流里用**文字卡**——分类色块底 + 该分类 Phosphor 图标（大号、低透明度）+ 标题 2–3 行 + 源名；高度固定为图卡的约 60%，避免一列全是文字时版面塌陷。不要用随机图/占位照片。
- 图片加载失败时降级为同一文字卡。
- 无日期：见 §4，显示「展期…」或「最近收录」。
- 英文条目：本轮原样显示英文标题，不做机翻（Q3）。

## 7. 界面与分区
- 技术栈以仓库实际为准：Python 生成静态页 + `web/` 原生 JS/CSS，部署 GitHub Pages。**不引入 React/shadcn/Zustand/Motion 等 npm 依赖**；灵记 v0.2 设计语言用 CSS 变量实现；动效用 CSS transition；Phosphor 图标以内联 SVG 加入 `shiguang/site/icons.py`（只放用到的几个）。
- 视觉：主色正红 `#D7282F`（少数派红）；支持暗色模式（`prefers-color-scheme` + 现有切换，如有）；以 iPhone 17 Pro 视口（402×874 pt）为主验收尺寸，桌面不变形即可。
- 「好玩」「好买」两页：顶部分类筛选（纯图标 + 可读 aria-label）；双列瀑布流大图卡片、柔和杂志感；按时间新→旧。
- 首页「今日」：好玩、好买各一块，每块 5 条，点「更多」进完整列表（MRD 第 4 条）；摘要只在「今日」首页。
- 卡片：图（或文字卡）、标题、源名、相对时间/展期、最多 3 个标签；点击外链新窗口打开原文。
- 不改「好看」资讯页结构（已定：无摘要、新→旧连续列表、图左置），只换新视觉变量。

## 8. 验收标准
1. 13 个试跑源条目（按 Q1 结果）出现在对应栏目和分类下，排序新→旧。
2. 同一 URL / 同一标题的重复条目只出现一次（单测 + 用 tg.db 实数据抽查）。
3. 无图条目显示文字卡，没有破图、空白框；图片 404 时也降级。
4. douban-events、ucca 不出现假日期；ucca 展期解析正确；已结束展览不展示。
5. Apps_Share 没有任何以「标签：」开头的标题。
6. 首页好玩/好买各 5 条 +「更多」；某分类为空时整块隐藏而不是显示空框。
7. iPhone 17 Pro 尺寸（402×874）亮/暗两种模式截图各 1 张：好玩、好买、今日首页，附在实现 PR。
8. 主色为 #D7282F，图标全部为 Phosphor；不新增 npm 依赖。
9. 现有测试全部通过，新增测试覆盖 §4 §5 §6。
10. 公开版不泄露内网内容（`tests/test_public_privacy.py` 通过）。

- Q1 哪些源首批上线？**建议**：13 个全上（都无报错）；但 steam 只上带图或标题像「新品/促销」的条目，appinn 只上软件相关（过滤 VPS/优惠类）。满一周按运维统计再砍。

- Q3 英文标题要不要翻译？**建议**：本轮不翻，原样显示；以后单独评估成本。

- Q6 Apps_Share 取不到 App 名时？**建议**：直接不展示，不用标签串充当标题。
- Q7 已结束的展览/活动？**建议**：不展示；无法解析日期的活动 14 天后自动下架。
