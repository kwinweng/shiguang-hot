OpenAI 正式发布 GPT-6.2 Astra 和 GPT-6.2 Sol。距离上一代 Astra 旗舰发布已过去两个半月，原定 10 月推出的 GPT-6.1 Astra 因安全评测未达标被取消，OpenAI 直接跳到了 6.2。 新旗舰重点提升专业工作、AI 科研和视觉设计能力。按照 OpenAI 官方测试，Astra 在 Agents' Last Exam 长流程专业任务评测中，比上一代高出 5.2 分，单项任务成本不到三分之一。独立评测机构 Artificial Analysis 给它的综合智能指数打出 62 分，比上一代提高 5 分，仅次于 Claude Fable 5.2 的 65 分。 Astra 还成为 OpenAI 首个在「AI 自我改进」能力上达到 High 评级的公开模型。它能协助研究员排查 AI 训练故障、优化底层计算代码、从头训练小型模型，以及改进已有模型。OpenAI 以研究员在 2024 年的工作效率为基准，认为 Astra 带来的帮助，相当于给每位研究员增配一名经验丰富的研究工程师。 日常使用更值得关注的是 Sol。官方称，在 FrontierCode 2.0 编程评测中，6.2 Sol 仅落后 Astra 0.5 分，单项任务成本约为后者的五分之一。 Artificial Analysis 的 Coding Agent 指数却没有体现出同样的进步。GPT-6.2 Astra 与上一代持平，Sol 反而下降了 3 分。Epoch AI 用真实研究任务测试，Astra 平均只达到该机构员工工作标准的 65%，比 Claude Fable 5.2 低 17 个百分点。 部分提前试用的开发者评价更尖锐。知名开发者 Theo Browne 称，Astra 在他的编译器优化项目上连续工作 7 天，没有做出有效改进，生成的版本反而慢了 56%。他认可模型的 3D 设计和代码审查能力，但认为它难以持续推进大型项目。Matt Shumer 则直言，自己测试的两个新模型「几乎没法用」。 安全系统卡还披露，两款模型在某些测试中更容易隐瞒任务遇到的障碍，例如没有告诉用户缺少文件或搜索工具不可用。OpenAI 已通过 Codex 的额外指令缓解这一问题，但仍在调查原因。 目前两款模型已在 ChatGPT Work、Codex 和 API 上线，付费用户可以使用。Astra 的 API 输入、输出价格均下调 20%，分别为每百万 Token 8 美元和 40 美元。Sol 维持上一代价格，分别为 2 美元和 10 美元。 信源 动察 Beating 频道 · 动察 Beating 交流群
