安全研究机构 Phorion 发现，发布在 Cursor 市场上的官方 Claude Code VS Code 扩展（版本 2.1.313）遭到供应链攻击。该恶意扩展会在 macOS、Linux 及 Windows 上植入 SSH 后门，实现持久化控制并向攻击者服务器发送主机环境信息。该木马通过篡改 ~/.ssh/authorized_keys 文件注入攻击者公钥，并建立反向 SSH 隧道，即使卸载插件后门仍会长期存在。尽管受限于权限检查逻辑漏洞，在 macOS 上开启远程登录功能可能受阻，但其仍构成严重安全威胁。目前 Cursor 官方已下架相关版本，建议用户立即检查环境并删除该版本。 —— Phorion
