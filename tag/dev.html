百度文心 5.5 Flash Preview 正式开源

周二，百度宣布文心 5.5 Flash Preview 模型正式开源，采用 Apache 2.0 协议，模型权重与配套资源已上架 Hugging Face 和 ModelScope。开发者可在本地部署与二次开发，支持 vLLM、SGLang 等主流推理框架。文心 5.5 Flash Preview 于 11 月 11 日发布，是基于此前开源的文心 5.5 Flash Base 的首个后训练版本。该模型采用 MoE 架构，总参数量 2800 亿，每个 Token 激活 140 亿参数，支持最长 100 万 Token 上下文，官方定位偏向编程、3D建模、知识工作与内容创作场景。百度此前已将文心 5.5 Flash Base 以同一协议开源。 —— IT之家

Take-Two下架《GTA 6》PC重编译项目

由15岁开发者“NotRexed”发起的《GTA 6》PC重编译项目“Leonida”因收到Take-Two的DMCA版权删除通知而关闭。该项目旨在将此前泄露的Xbox版《GTA 6》代码逆向工程并重构为原生PC版本。Take-Two 的IP维权团队已采取行动，删除了包括GitHub主仓库及超过2900个分叉版本。尽管目前仍有其他团队如“VIctory”项目试图通过模拟器或兼容层(如XCL)在PC上运行游戏，但Take-Two正加大力度阻止这一进程。据传《GTA 6》官方PC版可能在未来几个月内发布，这或将早于民间非官方移植的实现。 —— The Verge
