最近对上下文管理和节约 token 还挺有心得的，总结了一下，不需要什么别的工具，就这4件事重要：

1. 减少 agent 启动后初始 token 量 • 精简 skill 列表 • 把重要但不需要自动调用的 skill 改成只能手动调用 • 详细阅读 agent 配置文档，去掉不必要的 system tools, plugins, mcp, etc 比方说我的 claude 默认关闭 artifact, 只有需要做设计的时候通过命令行 alias 主动打开 2. 尽量命中缓存 即不要总是在会话缓存过期后继续聊，可以在 statusline 里增加对缓存的显示，还可以做成提醒工具，在缓存快过期时提醒关注 3. 控制 context 使用的百分比 • 合理设置 auto compact 的数值，不过尽量不要让会话触及到这个线 • 如果你用 herdr, 可以给 root AGENTS.md 里说明，当 context 超过某个百分比就自动总结进展并 handoff 给新的 tab 4. 不同的任务用不同的模型 + effort 配置 目前我自己的 build: • 设计: opus xhigh • 规划: fable high • 写代码: opus xhigh / gpt sol high • 审代码: gpt astra medium • 验收走查: sonnet xhigh 我有一个 coordinator skill, 它会让当前会话成为只做协调工作的主会话，拆分任务，根据任务类型开启 tab 使用不同的模型

这段时间我给自己定了个目标：用 AI 做点比小工具更有野心的东西

至于做什么，想来想去还是从小时候开始最踏实，也就是那些玩到天黑的游戏，和那些"要是能做成游戏就好了"的念头。下面四个大多是这么来的。代码基本是 AI 写的，我负责出主意、试玩、挑毛病，还有在它说"已修复"之后再去确认一遍。它们离成熟的游戏还有距离，但每一个都能从头玩到尾，我自己也挺喜欢。 燃烧战车 Burning Chariot 复刻的是新浪游戏大厅当年那款《燃烧战车》：调角度、蓄力度、算风，用会被炸烂的地形把对面送下地图。小时候玩这个全靠手感和玄学，这次我给它加了一个肉鸽"远征模式"：十五层、三个 Boss，一路攒遗物、改武器，最后能把一发普通炮弹叠成"分裂 × 集束 × 燃烧 × 余震"的灾难。想怀旧的话还有经典对战，燃料照样紧，风照样不讲道理。 止水 Stillwater 做一只鸭子，在江南的河上漂过慢悠悠的一天。灵感来自那种把相机绑在真鸭子背上、让它游过村子的视频：镜头贴着水面，白墙黑瓦从两边滑过去，石桥和自己的倒影合成一个整圆。想偷懒可以按 F 全程随波逐流；勤快点的鸭子可以起飞钻桥洞、潜水捞螺蛳、冲岸上的人嘎嘎叫讨面包，顺便把走散的六只小鸭找回来。我承认，做这个的主要动机是想当一天鸭子。 满地红 Firecrackers 年三十傍晚，南方乡下。大人在屋里打牌，爷爷在门口烤火打瞌睡，你兜里揣满了炮，手里捏着一根香。这是一个第一人称的小沙盒，没有任务，院子里、村道上、田里看得见的东西都可以拿来试试。现实里这么干是要挨骂的，在这里只会被记成一种新"花样"。 Kindlewick 这个和童年无关，是玩 Forager 玩上头之后的产物。你是 Wick，世上最后一根蜡烛。采集、合成、盖房子，把熄灭的大地一点点重新点亮。表面是个温吞的种田建造游戏，底下藏了七个玩法各不相同的地牢（挖矿、滑行、卡节奏、潜行、守城……），还有一个地下世界和一个正经的结局，通关一个多小时。
