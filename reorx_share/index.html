我突然意识到一件事情

比方说现在 Claude Code 之类的这种 agent harness 其实也有很多可定制的功能，比如 mod，还有一些像 PI 和 DSH 这样自定义程度非常高的 harness。但是我发现现在我自己几乎不怎么去调整。如果真的遇到有什么问题需要去弄的话，也是很短的时间让 agent 自己去搞定了。 说白了，现在折腾工具给我带来的乐趣，远没有让 agent 多跑一会儿、把额度利用得更充分对我来说更有吸引力。但以前不是这样。以前在用 IDE 的时代，我可以花一整天的时间折腾 Vim 的配置、VS Code 的插件等等这些东西。 这让我思考为什么有这种差别呢？是我变了吗？我感觉自己并没有变，我还是乐意去给我现在的工作流添砖加瓦，只不过他们不再需要我自己动手，很多时候一句话让 agent 就做好了。我想真正的原因是：在以前那个一天可能只能开发一个功能的时代，人的注意力很容易被分散，写代码是一种平和的快乐。所以在这种平和的快乐之中，我很容易会想通过折腾生产力工具来得到新的刺激。但是在 AI Coding 的时代，使用 agent 本身就是最大的刺激了，且阈值被提高，折腾工具再也不能像以前那样让我满足了。
